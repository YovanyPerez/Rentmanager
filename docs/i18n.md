# Internationalisation (i18n)

Requirements live in `AGENTS.md` section 22. This document explains the conventions and how to work with translations.

## Stack

- Angular + Transloco (`@jsverse/transloco`)
- One JSON file per language: `frontend/public/assets/i18n/{es,en}.json` (served at `/assets/i18n/*.json`)

## Key namespaces

| Namespace | Used for |
|---|---|
| `common.*` | Shared actions (save, cancel, edit, delete, search) |
| `nav.*` | Navigation and menu entries |
| `auth.*` | Login, register, session |
| `dashboard.*` | Dashboard page |
| `properties.*`, `owners.*`, `tenants.*`, `contracts.*`, `payments.*`, `maintenance.*` | Feature pages |
| `enums.*` | Display labels for backend status/role codes |
| `validation.*` | Form validation messages |
| `errors.*` | Backend error-code mapping and generic errors |

## How to add a translation

1. Add the key to `es.json` **and** `en.json` (parity is mandatory).
2. Use it:

```html
<h1>{{ 'properties.title' | transloco }}</h1>
```

```ts
// Only when text must be produced imperatively (e.g. snackbar, guard message)
private readonly i18n = inject(LanguageService);
this.i18n.t('messages.propertyCreated');
```

3. Never build sentences by concatenating translated fragments. Use parameters:

```json
{ "messages": { "welcome": "Welcome, {{name}}" } }
```

## How to add a language

1. Copy `en.json` to `pt.json` and translate the values.
2. Register it in `app.config.ts`: `availableLangs: ['es', 'en', 'pt']`.

No component changes are required.

## Backend error codes

The backend returns stable codes, never human-readable text:

```json
{ "code": "PROPERTY_NOT_FOUND" }
```

Angular maps them to `errors.<CODE>`, falling back to `errors.UNKNOWN`. Validation errors return `{ field, code }` per field; map those with `validation.<CODE>`.

## Status and enum labels

Business logic uses language-neutral codes (`RENTED`, `ACTIVE`, `OVERDUE`, ...). Translate the display label only:

```html
{{ 'enums.propertyStatus.' + property.status | transloco }}
```

## Language persistence and switching

`LanguageService` stores the selection in `localStorage` (`rentmanager.lang`). On startup the language is resolved as: saved value → browser language → `es` (with `en` as Transloco fallback). Switching happens at runtime via `LanguageService.use(lang)`; no rebuild or reload is needed.

## Locale-aware formatting

Use Angular's pipes with the active locale passed as a parameter (Angular formats via the native `Intl` API; no locale data registration is needed):

```html
{{ contract.startDate | date: 'mediumDate' : undefined : i18n.lang() }}
{{ payment.amount | currency: 'USD' : 'symbol' : '1.2-2' : i18n.lang() }}
```
